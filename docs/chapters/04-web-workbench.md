# 第四章补充：可视化聊天工作台

## 启动与操作

在 IDEA 中继续运行 `CloudCustomerServiceApplication`，浏览器打开 <http://localhost:18080/>。

前端文件位于 `src/main/resources/static/`，由 Spring Boot 直接提供。无需 Node.js、npm、跨域代理或独立前端服务，API Key 继续只由后端环境变量读取。可执行 JAR 同样包含这个页面。

| 区域 | 功能 |
| --- | --- |
| 左侧会话 | 新建与切换独立会话，首条消息自动成为会话标题 |
| 中间聊天 | 发送问题、查看回复、等待状态和错误；Enter 发送，Shift + Enter 换行 |
| 右侧洞察 | 意图中文名称、订单号、模型自评置信度、缺失字段和原始结构化 JSON |
| 历史回复下方 | 点击“查看这条回复的意图识别”，切换查看对应结果 |
| 清空记忆 | 确认后调用后端清空接口，页面保留旧记录并插入分隔线 |

示例卡片只填入草稿，点击发送才会调用模型。正常每条消息仍由后端发起两次模型调用，分别分类和生成回复。模型 JSON 只展示为识别详情，不混入客服对话记忆。

## 页面状态与边界

- 使用 `sessionStorage` 保存当前标签页的会话列表、页面消息与草稿；刷新能够恢复。存储不可用时显示提示，当前页仍可继续操作。
- 页面记录与后端模型记忆分开：后端重启后历史失效，前端不会把旧页面记录重新发送给模型。清空记忆也不会删除页面记录。
- 请求进行中禁用发送、新建、切换与清空，避免本页面并发写同一会话；输入框仍可写下一条草稿。没有跨标签页并发协调，也不要在发送过程中刷新或关闭页面。
- 空白消息不能发送，最多 4000 个 JavaScript UTF-16 字符单位，匹配后端限制；处理中文输入法组合状态，避免选词回车直接发送。
- 错误显示在当前会话中，不自动重试。请求失败时后端可能已保存用户消息，故提示避免重复发送。
- 所有用户文本、模型回复与 JSON 都通过 `textContent` 显示，未作为 HTML 插入，也未新增 Markdown 渲染或第三方 CDN。
- 手机端会话列表横向滚动，识别面板默认折叠；点击历史识别按钮会展开并滚动到详情。页面支持键盘焦点、原生对话框与减少动画偏好。

这是当前无登录的本地学习应用，没有增加身份认证、订单查询、退款办理或会话持久化。模型仍可能生成未经验证的商城入口、政策和步骤，页面标注“AI 回复仅供参考”。

## 文件

- `index.html`：页面语义结构、空状态、图标与清空确认框。
- `app.css`：云杉配色、三栏布局、等待/错误/消息样式与响应式适配。
- `app.js`：同源 API 调用、会话状态、纯文本渲染、存储恢复和交互。
- `favicon.svg`：本地云杉图标。

## 实测（2026-09-13）

后端：JDK 17 的 `./mvnw -B -ntp package` 通过，原有 39 项测试通过。JavaScript 通过 `node --check` 语法检查；静态文件包含在可执行 JAR 中。IDEA 正在运行应用，访问根路径显示前端。

在应用内浏览器通过真实界面操作和真实 Qwen 调用验证：

1. 首次加载创建会话，示例卡片填入“我的订单是 A10001”，发送后显示客服回复。
2. 同会话再问“我想把它退掉”，识别面板显示退货退款、A10001、95%。
3. 新会话问旧订单，订单号为空并提示补充订单号；切回原会话恢复原消息和草稿。
4. 刷新后仍有两轮记录和未发送草稿。
5. 清空确认后出现分隔线，再问旧订单未识别出 A10001；再次打开确认框按 Escape 取消，不重复清空。
6. 临时模拟浏览器断网，发送显示连接错误并恢复按钮状态；测试后已恢复网络。`<b>网络错误测试</b>` 按原文显示。
7. 桌面截图检查通过；390×844 手机视口与 320px 窄屏检查无横向溢出，移动详情可以展开。该项是浏览器视口模拟，不是真机测试。

本次模型回复出现了未验证的“7天无理由退货”和 App 操作建议。前端正确展示了实际返回，但这不代表政策真实；后续知识库与真实业务工具仍按章节推进。
